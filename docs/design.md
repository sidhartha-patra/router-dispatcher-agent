# Design

## Product intent
This repo demonstrates a production-friendly alternative to hidden prompt routing: intent scoring, deterministic handlers, fallback behavior, and approval gates for high-risk routes.

## Real components
CLI, API, router, confidence threshold, approval gating, audit trail, tests, and evals are real.

## Mocked or simulated components
Research snippets, code guidance, data guidance, and meeting times are deterministic fakes.
